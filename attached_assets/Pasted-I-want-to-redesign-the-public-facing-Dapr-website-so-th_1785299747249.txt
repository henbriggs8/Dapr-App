I want to redesign the public-facing Dapr website so that it visually matches the direction of our new native Dapr app.

The attached Uber screenshots are a reference for the layout, hierarchy, whitespace, navigation, large typography, booking-first homepage, cards, and overall simplicity. Do not copy Uber's branding or assets. Use these only as UX/layout inspiration and keep the website distinctly Dapr.

IMPORTANT — protect the existing architecture

This task is primarily a website/frontend redesign.

The Dapr backend is also being used by separate native SwiftUI customer and provider apps being developed outside this Replit project.

Do NOT:

rename or remove existing /api/* endpoints
change API response shapes
change API request bodies
change authentication behavior
change Clerk integration
change Stripe/payment verification logic
change booking ownership/security logic
change database schemas unless absolutely necessary
change existing backend behavior that could break the native Swift apps
remove any functionality currently required by the native apps

If something in this redesign appears to require a backend/API change, STOP and explain what would need to change before making that change.

Existing API contracts should remain backwards-compatible.

Lots of whitespace
Large rounded cards

Minimal borders
