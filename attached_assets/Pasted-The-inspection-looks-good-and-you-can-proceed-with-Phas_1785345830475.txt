active_provider

The native app should consume GET /api/provider-applications/me and render its own native screens based on:

application status
verification requirement
setup eligibility
active-provider state

The website and SwiftUI app share backend data, not frontend screens.

Do not allow the admin status endpoint to change an application to any arbitrary status.
